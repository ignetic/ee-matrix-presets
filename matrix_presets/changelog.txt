Changelog for Matrix Presets
===============================


## 1.3.7
-- Fixed new presets overwriting preset 10 once a field had 10 or more presets
-- Fixed presets loading into the wrong columns after Matrix columns were added or reordered (new presets are saved by column ID; older presets still load by column position)
-- Fixed checkboxes and radios not saving or loading their checked state (presets saved before 1.3.7 leave them unchanged)
-- Fixed select values containing quotes breaking the load, and missing options being added with the wrong value
-- Fixed empty presets being saved when the Matrix has no rows
-- Fixed Assets files not loading (files are now added through the Assets field, with their thumbnails, and can be removed/reordered)
-- Fixed Channel Images Select images not loading (the picker is rebuilt with the loaded images)
-- Fixed JS errors when loading a missing preset, or an Assets column when Assets isn't loaded
-- Security: preset names and loaded values are escaped (preset names could inject HTML into the CP)
-- Security: stored presets are unserialized as arrays only (PHP 7+)
-- Performance: presets are only requested on publish pages with Matrix fields

## 1.3.6
